# last30days

Research current trends across Reddit, X, and the web over the last 30 days.

## Best For

- Rapid market scans
- Real-time content opportunity discovery
- Prompt or messaging research tied to current sentiment

## What It Does

- Collects recent multi-source signals
- Identifies repeated patterns and market narratives
- Produces copy-paste prompts and action ideas

## Install

```bash
mkdir -p "$HOME/.codex/skills"
cp -R last30days "$HOME/.codex/skills/last30days"
```

## Use

```text
/last30days <topic>
```

## Output

- Top patterns and themes
- Reddit sentiment summary
- X signal snapshot
- Actionable prompt + opportunities
