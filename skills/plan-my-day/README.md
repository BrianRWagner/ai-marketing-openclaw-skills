# plan-my-day

Generate an energy-aware, time-blocked daily plan focused on top priorities.

## Best For

- High-output days with multiple priorities
- Reducing context switching and reactive work
- Building a consistent execution rhythm

## What It Does

- Identifies top 3 outcomes for the day
- Maps tasks to peak/secondary energy windows
- Produces a practical schedule with buffer and review blocks

## Install

```bash
mkdir -p "$HOME/.codex/skills"
cp -R plan-my-day "$HOME/.codex/skills/plan-my-day"
```

## Use

```text
/plan-my-day
/plan-my-day 2026-02-20
```
