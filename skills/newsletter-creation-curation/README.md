# newsletter-creation-curation

Advanced framework for building industry-specific newsletters with cadence, positioning, and workflow guidance.

## Best For

- Founders and marketing leaders launching a newsletter motion
- GTM teams aligning thought leadership with pipeline goals
- Category-building programs in B2B markets

## What It Does

- Maps strategy by goal, vertical, company stage, and role
- Recommends positioning, publishing cadence, and channel mix
- Provides tactical playbooks for execution

## Install

```bash
mkdir -p "$HOME/.codex/skills"
cp -R newsletter-creation-curation "$HOME/.codex/skills/newsletter-creation-curation"
```

## Recommended Usage

- Define objective first: lead gen, thought leadership, or category ownership
- Select the closest scenario path in `SKILL.md`
- Execute the suggested weekly system and iterate by performance data
