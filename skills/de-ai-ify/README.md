# de-ai-ify

Remove AI-generated phrasing and restore natural human voice in written content.

## Best For

- Blog posts that sound generic or robotic
- Sales copy with buzzwords
- Social posts that need clearer personality

## What It Does

- Removes overused AI transitions and cliches
- Replaces hedging and corporate jargon with plain language
- Preserves meaning while improving readability and tone

## Install

```bash
mkdir -p "$HOME/.codex/skills"
cp -R de-ai-ify "$HOME/.codex/skills/de-ai-ify"
```

## Use

```text
/de-ai-ify <file_path>
```

## Output

- A rewritten file with a `-HUMAN` suffix
- A concise changelog of tone and phrasing improvements
